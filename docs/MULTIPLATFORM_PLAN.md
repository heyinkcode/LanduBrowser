更新日期：2026-11-03。采用用户设备本地运行方案，不建设集中管理后台、云手机或流量中转，不要求维护者购买运营服务器。

| 平台 | 当前状态 | 后续范围 |
| --- | --- | --- |
| Windows x64 | 原 v1.0.26 稳定版保留，新修复提供预览候选 | 安装升级、完整 UI、签名与更新机制 |
| Android ARM64 | 完整 Chromium APK 已构建，小米 Android 15/16 的指定 UA-CH/RAF 与配置检查通过 | 完整管理表单、生命周期、媒体、代理失败、负载与更多机型 |

| iOS | 无客户端 | 暂不承诺交付，不用云电脑替代 |

AndroidNative 是当前内核工程，Androidapp 是历史系统 WebView 原型，两者不能混称。桌面与安卓配置格式、扩展、RPA 和 API 能力尚未完全对齐，不能因同名选项就宣称等价。

GitHub main 存官网，source 存应用源码，Releases 分发本地构建的安装包。仓库不保存账号环境或转发网页流量；不会自动启动 Actions 编译或保留大型 Artifact。手机使用用户自己的网络，独立代理与系统 VPN 均为可选，不内置免费线路。

当前已交付与待验收细节见 [Android 指南](ANDROID.md)、[测试范围](TESTING.md) 和 [发布说明](RELEASE_NOTES.md)。原有功能及贡献继续保留，软件免费；可选网络服务单独计费。
