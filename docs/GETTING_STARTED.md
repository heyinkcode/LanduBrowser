# 岚渡浏览器使用指南

[返回项目首页](../README.md) · [官网](https://heyinkcode.github.io/LanduBrowser/) · [开源说明](OPEN_SOURCE.md)

## 1. 先确认你下载的是什么

岚渡浏览器是基于 [OpenBrowser](https://github.com/sheying2013/OpenBrowser) 二次开发的免费桌面浏览器环境管理工具，核心业务逻辑来自原项目。当前仓库先提供官网和文档，尚未发布岚渡桌面端安装包与完整客户端源码。

- 客户端请认准 [heyinkcode/LanduBrowser 的 Releases](https://github.com/heyinkcode/LanduBrowser/releases)，以实际发布的资产为准。
- GitHub 的 `Source code (zip)`、`Download ZIP` 是源码压缩包，**不是可双击运行的 Windows 安装程序**。
- 本仓库的 `npm start` 只预览官网，不启动客户端。
- 原项目的源码启动方法请查看 [OpenBrowser 中文 README](https://github.com/sheying2013/OpenBrowser/blob/main/README_CN.md)，不要把上游安装包误认为已换肤的岚渡版本。

以下介绍岚渡桌面界面的基本操作。具体入口和支持情况以你安装的版本为准。

## 2. 创建第一个环境

1. 打开「环境管理」，点击「新建环境」或左侧「新建浏览器」。
2. 在「平台账号配置」中填写环境名称，例如「日常工作」。按需选择分组、标签和启动地址。
3. 在「代理配置」中选择「本地直连」，或使用你已有的代理服务。
4. 在「指纹配置」中检查系统、语言、时区及其他参数。不了解的选项先保留默认，不要为追求某个检测分数随意修改。
5. 保存后回到环境列表，点击启动按钮。

每个环境使用独立的浏览器 Profile。不同环境的 Cookie、缓存和本地存储分别管理，但这不等于不同环境自动拥有不同公网 IP。

## 3. 管理代理与网络

### 本地直连

使用设备当前的网络出口，不需要填写代理地址。操作系统上的 VPN 或其他网络工具是否影响出口，取决于该工具的实际工作模式。

### 独立代理

1. 在「代理管理」创建代理，按照服务商提供的信息填写协议、主机、端口，以及需要时的账号和密码。
2. 使用界面中的检测功能确认代理可用，再保存。
3. 编辑目标环境，在「代理配置」中选择对应代理节点，保存后重新启动环境。
4. 检查实际出口信息。连接成功不代表目标网站一定可访问。

不同环境需要不同出口时，必须分别配置相应的代理资源。**只开启一个系统 VPN，并不等于每个环境都有独立 IP。**

需要可选的 VPN / 网络服务，可了解 [岚渡云（推广）](https://app.landucloud.com)。详见 [推荐服务说明](RECOMMENDED_SERVICES.md)；它不是软件的必购项目。

## 4. 分组、标签与表格

- **分组**：按店铺、项目或工作类型组织环境。
- **标签**：为环境添加便于检索的说明。
- **列宽**：在支持调整的列标题分隔处拖动，留出适合名称与参数的空间。
- **批量操作**：先勾选环境，再执行对应操作；删除、覆盖、导入前先确认对象并备份。

## 5. 指纹参数不是“通行证”

项目沿用 OpenBrowser 的语言、时区、User-Agent、Canvas、WebGL、WebRTC 等设置。参数应符合实际使用场景并保持合理一致。

- 某个第三方检测页的红色提示不等于网站官方封禁结论。
- 字体、Emoji、设备特征等取决于内核、系统与实际配置，不承诺完全隐藏宿主环境。
- 环境隔离与指纹配置不保证匿名、不保证“零风险”，也不保证账号不会受到平台限制。
- 这是管理与测试工具，不应拿来绕过目标平台的规则。

## 6. 扩展与自动化

「应用中心」管理扩展；「窗口同步」「自动脚本」「API & MCP」提供原项目中的自动化入口。新脚本先在不含真实账号的测试环境运行，确认点击、输入及页面切换的范围。

本地 API 默认用于本机集成。不要直接将其暴露到公网，也不要把真实账号凭据写进公开脚本或问题反馈中。

## 7. 本地数据与备份

环境配置和浏览器 Profile 主要保存在本机。为兼容已有环境，当前岚渡开发版本保留原项目的数据目录约定；Windows 上常见根目录为 `%APPDATA%\openbrowser`，自定义路径以应用实际显示为准。

- 更新或迁移前，先关闭正在运行的环境，再备份实际数据目录。
- 不要只复制程序文件就认为账号环境已备份。
- 不要删除旧目录来“清空缓存”，除非确认不再需要其中的数据。
- 如启用原项目的远程备份功能，数据会按你的设置传到对应服务，不应再理解为仅保存在本机。

## 8. 常见问题

### 软件收费吗？

岚渡浏览器软件免费使用。代理、VPN、服务器等外部资源如有费用，由对应服务单独收取。

### 安卓和 iPhone 能用吗？

本仓库没有 Android / iOS 客户端，也没有手机远程管理端。手机能浏览官网，不代表能在手机上运行桌面环境。

### macOS 和 Linux 呢？

上游 OpenBrowser 提供 macOS 和 Ubuntu 的支持及打包路径；岚渡当前主要在 Windows 本地适配，本仓库暂未发布或独立验证这些平台的岚渡客户端。

### 下载页为空怎么办？

说明还没有在此仓库发布安装包。不要把源码压缩包当安装包；可以关注仓库的发布通知，或先研究上游项目。

### 怎么反馈问题？

在 [Issues](https://github.com/heyinkcode/LanduBrowser/issues) 提交系统版本、应用版本、复现步骤、预期结果和脱敏截图。截图中请遮挡密码、Cookie、令牌、代理地址及个人信息。
