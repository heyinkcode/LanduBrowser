# 官网开发与维护

[返回项目首页](../README.md)

## 目录

```text
LanduBrowser/
├── index.html                 官网首页
├── styles.css                 响应式样式与轻量动效
├── site.js                    手机导航与界面预览切换
├── assets/                    Logo 与示例界面截图
├── docs/                      使用指南、开源说明、推荐服务
├── scripts/serve.mjs           本地静态预览服务器
├── package.json               预览命令，无第三方依赖
├── .nojekyll                  GitHub Pages 静态站标记
└── LICENSE                    MIT 与上游署名
```

## 本地启动

安装 Node.js 18 或更新版本后，在仓库根目录运行：

```bash
npm start
```

浏览器访问 `http://127.0.0.1:4173`。预览仅监听本机；按 `Ctrl+C` 停止。自定义端口可运行 `node scripts/serve.mjs 4180`。

官网为普通静态页面，无需 `npm install` 或构建命令。此命令不能启动桌面客户端。

## GitHub Pages

仓库 Pages 使用 `main` 分支的根目录。发布地址：

**https://heyinkcode.github.io/LanduBrowser/**

在仓库 Settings → Pages 选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。推送后等待 Pages 构建成功再验收，不把“代码已推送”视为“网页已上线”。

如果换自定义域名，需另行配置 Pages 域名、DNS 与 HTTPS。本仓库当前不依赖私人域名，也不部署客户端后端服务。

## 内容更新原则

1. 保留首页、README 与开源说明中的原作者链接及 MIT 署名。
2. 软件免费与外部服务收费分开写，不用“免费”描述需另行购买的代理。
3. 先发布真实客户端资产，再改首页下载状态；发布页为空时不出现虚假的直接下载按钮。
4. 不把上游支持的平台写成已经独立验证的岚渡发行版。
5. 截图使用示例数据，不能带入真实账号、Cookie、代理密码或个人信息。
6. 岚渡云推荐集中在 README 与推荐服务文档中，标记为推广，不伪称原作者推荐。

## 发布前检查

- 桌面与手机布局没有横向溢出，导航与按钮可点。
- 预览切换可以用键盘操作；系统开启减少动态效果后不播放入场动画。
- 页面没有引用本机路径；图片、CSS、JS 与内部锚点可加载。
- 原作者、仓库、文档、Releases、岚渡云链接指向正确位置。
- 没有提交 `.env`、账号凭据、真实环境、浏览器内核或个人数据。
- 上线后检查 Pages 构建状态及页面 HTTP 响应。

## 关于桌面项目

客户端的内部数据目录和包名不应为了改品牌随意变更，避免已有环境无法识别。本网站不包含客户端运行时，也不会连接访客的本地 Profile 或代替客户端管理环境。

## 客户端版本发布顺序

1. 本地构建并验证安装包，排除 Profile、日志、缓存、密钥和私有配置。
2. 同时整理对应应用源码、构建说明、第三方许可和 SHA-256 清单。
3. 上传到 GitHub Releases，核对文件大小和哈希后公开发行版。大文件放在 Release 资产，不提交到 Git 历史。
4. 更新首页、README 和 `docs/DOWNLOADS.md` 的版本与真实下载链接，再推送官网。
5. 检查 Pages 构建与公开下载地址。变更 GitHub 用户名时，同步仓库、官网 canonical、客户端更新检查和文档链接。
