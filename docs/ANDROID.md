## 当前版本

[v1.0.26-android.20261104.2 预览版](https://github.com/heyinkcode/LanduBrowser/releases/tag/v1.0.26-android.20261104.2) 提供完整 Chromium Android 内核，在手机本地运行。APK约548 MB，ARM64，内核为 `156.0.8078.48`，包名为 `com.landu.browser`。

构建最低系统为 Android 10；本次真机仅覆盖小米 Android 15 和 16 的指定检查，不能据此宣称所有机型和系统均已兼容。当前为开发签名预览包，尚未上架应用商店，完整功能仍在验收。

软件免费，不需要岚渡账号、自建服务器、云手机或付费激活。直接使用手机自己的 Wi-Fi、移动数据或系统 VPN；GitHub 只分发代码、文档和安装包，不转发网页流量。

## 安装与更新

1. 从 [预览版发布页](https://github.com/heyinkcode/LanduBrowser/releases/tag/v1.0.26-android.20261104.2) 下载 `LanduBrowser-Android-arm64-latest.apk` 和 `SHA256SUMS.txt`，核对 SHA-256。
2. 首次安装时，按 Android 提示授权当前浏览器或文件管理器安装该 APK；无需关闭系统安全防护。
3. 更新前保存编辑，在管理页选择“更多 → 关闭当前环境”，等环境退出后安装新包。已验证本次同签名保留数据更新；不要通过卸载旧版来解决签名冲突，先备份并反馈。
4. 打开岚渡，新建环境，填写名称和启动地址，保存后启动。若出现浏览器首次启动引导，按自己的选择完成后继续。

## 代理与系统 VPN

- 代理留空：使用手机当前网络，包含系统 VPN。“本地直连”不表示绕过 VPN；规则模式下国内网站直连、国外网站走 VPN 可以同时存在。
- VPN 按应用分流时，把岚渡浏览器加入需要代理的应用列表。最终出口由 VPN 的规则和实际连通性决定。
- 独立代理：先选 HTTP / HTTPS / SOCKS5，再填 `主机:端口`，例如 `192.0.2.10:1080`；地址不必手填协议前缀，完整 URI 粘贴也可识别。
- 需要认证时，账号、密码分别填写；不要将密码、订阅链接或服务网站地址塞进主机栏。示例地址不可用于连接。
- 保存代理后关闭并重启环境。SOCKS5 与系统 VPN 可以组合，但选择了环境代理后应核对该环境的实际出口。

## 语言、时区和定位

可选择基于出口 IP 的策略或固定值，并设置检测失败时的回退语言。修改后重启环境。选择“洛杉矶”时区只改变相应区域配置，不能把公网 IP 自动变成洛杉矶；出口依然来自真实网络或代理。

## UA-CH 与 RAF 独立设置

在环境编辑页找到 **User-Agent 与 UA-CH**：默认自动使用真实内核版本；可读取推荐值，或关闭自动模式后自定义 UA、Chrome 完整版本、平台、平台版本、架构、位数、型号、navigator.platform、品牌列表、完整版本列表、Mobile、WoW64 和 formFactors。有关联的品牌和版本必须一致。

**RAF 动画帧率** 是独立设置：跟随设备，或指定 1–240 FPS 上限。30 FPS 对应约 33.3 ms，60 FPS 对应约 16.7 ms 的理想间隔；设备刷新率、前后台状态和页面负载会影响实际值。设置不会伪造回调时间戳，也不能让繁忙页面强行保持恒定帧率。

两项都需保存并关闭、重启环境后生效。自定义 UA-CH 不会替换真实内核，也不保证消除第三方启发式版本告警。具体实测见 [测试记录](TESTING.md)。

## Google 网页登录与原页翻译

头像中的添加账号入口会显示“Google 网页登录”确认框，确认后在当前环境内打开 Google 登录网页。浏览器账号同步尚未接入。

打开外语网页后，在浏览器菜单点击“翻译”，当前页面直接显示译文。翻译状态收在侧边“译”按钮中，点击可展开查看状态和“原文”操作，面板5秒后自动收起。控件提供拖动与贴边交互，相关完整真机验收范围见测试记录。

- 本地原页翻译使用 Google ML Kit 的端侧模型，默认译为简体中文，正文在手机本地处理。首次使用通过手机网络下载所需语言模型，缓存后可离线翻译。
- 原生整页翻译沿用 Chromium 流程。存在可用服务配置时优先采用原生翻译，否则自动使用本地原页翻译。

翻译可以在未登录账号时使用。当前原页处理覆盖点击时主文档中可显示的文字，跳过输入值、可编辑区、代码块和禁止翻译区。图片文字、内嵌框架、Shadow DOM 及后续新增内容需要另外处理。机器译文可能存在误差，以原文为准。

翻译由 Google Translate 的端侧能力提供。[ML Kit 翻译说明](https://developers.google.com/ml-kit/language/translation)及 [服务署名要求](https://cloud.google.com/translate/attribution)。

## 字体与数据

中文与厂商字体隔离是指定本地字体名称过滤，保留下载的 Web 字体和字符回退；并非禁止显示中文，也不保证字体检测或 Emoji 风格告警消失。

环境配置导出与合并导入在“更多”中。默认仅新增缺少的 UUID，只有明确勾选更新才覆盖相同标识配置。配置文件不包含完整浏览数据或手机保存的密码，不能代替 Cookie、历史与整个 Profile 的备份；安卓配置文件也不能直接作为桌面 JSON 导入。

卸载应用可能删除本地数据。不要把真实配置、Cookie、代理密码、日志原文或含账号的截图上传到公共仓库。反馈时写明系统版本、安装包、复现步骤和脱敏截图。

## 与桌面端的差异

本地环境与指纹设置按移动端能力接入；扩展中心、窗口同步、RPA、桌面 Local API/MCP、桌面环境整包迁移和团队云管理没有在安卓版中实现同等能力。请以实际界面和测试范围为准。

需要可选网络服务，可了解 **[岚渡云（推广）](https://app.landucloud.com)**。这是维护者推广，不代表 OpenBrowser 原作者背书；服务独立计费，不购买也能免费使用软件。
