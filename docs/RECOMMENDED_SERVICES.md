## 需要网络服务？可以了解岚渡云

在管理多个浏览器环境之外，如果你还需要独立的 VPN / 网络服务，可以前往 **岚渡云** 了解。

### [访问岚渡云 → app.landucloud.com](https://app.landucloud.com)

网络服务与浏览器工具各司其职：岚渡浏览器用于管理环境，岚渡云是另外选择的网络服务。你也可以使用其他适合自己的服务。

## 与免费浏览器的关系

- 岚渡浏览器软件免费使用，**不要求购买岚渡云**。
- 岚渡云的套餐、价格、线路、客户端和可用地区，请以其页面及实际服务说明为准。
- 本文不承诺某种带宽、地区覆盖、可用率、网站访问能力或账号效果。
- 不需要将浏览器账号密码、Cookie 或环境备份交给网络服务商。

## VPN 与环境代理怎么搭配

**系统 VPN / 网络客户端**通常影响设备或指定程序的网络路径；**浏览器环境代理**则需要可供环境使用的代理协议、主机、端口与认证信息。

不能直接把服务网站地址或订阅链接填进浏览器的代理主机栏。如果你的服务提供可用的 HTTP / HTTPS / SOCKS 代理信息，才按说明填入「代理管理」并检测；如果只提供客户端，则按该客户端的方式配置，并验证实际网络出口。

同一个系统 VPN 不会自动为不同浏览器环境分配不同 IP。需要独立出口时，请确认服务能否提供对应的代理资源及使用条件。
