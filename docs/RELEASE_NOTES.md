# 岚渡浏览器 v1.0.28

本次完善 Windows 更新详情页，软件免费，基于 OpenBrowser 和 Chromium 二次开发。

## 本次修复

- 更新状态由版本检查结果渲染，修复首次打开详情页后被界面翻译覆盖成“尚未检查更新”的问题。
- 已是最新版本时隐藏“下载更新”，发现可下载的新版本时显示下载入口。
- 包含 v1.0.27 的认证代理检测时限修复、正式最新版选择和原生更新提示弹窗。

## 运行验收

- 使用打包运行时临时模拟旧版本号，实际读取 GitHub 正式发布，观察到原生升级弹窗。
- 点击“查看更新”进入设置页，页面保留发现新版的正确文案，并显示下载按钮。
- 恢复真实版本号后，显示已是最新版，下载按钮的 hidden 状态及计算样式 display:none 均已核对。
- 安装文件与 ZIP 核对归档完整性及改动源码。安装程序执行和自动覆盖升级尚未作本次验收。

## 下载与使用

[安装包、便携 ZIP、对应源码及 SHA-256](https://github.com/heyinkcode/LanduBrowser/releases/tag/v1.0.28)。Windows 10/11 x64 推荐选择完整版 EXE。下载完成后先退出旧程序，再继续安装。

软件联网启动后自动检查更新，运行期间每6小时复查，也可手动检查。更新提示在软件联网运行时显示。Android 最新预览见下载指南。
