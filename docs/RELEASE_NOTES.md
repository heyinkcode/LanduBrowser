# 岚渡浏览器更新说明


## 2026-11-05 · Android 1.0.26.20261105.2

- 修复安卓真机文字选区重复绘制时，`PaintChunker` 的端点重复记录诊断触发网页进程退出的问题。保留后续绘制更新选区端点的行为。
- 发行版本更新为 `1.0.26.20261105.2`，版本码递增为 `807804806`。内核版本为 `156.0.8078.48`。
- 真机覆盖安装核对环境目录、代理凭据及应用标识，原有数据保留。
- 本轮 Android 15 的验证范围为 32 项端点回归、8 种文字布局及连续浏览，详细结果见测试记录。
- Android 16 已补充验证此前的 `1.0.26.20261105.1`，记录了 21 次导航中的 4 次超时及重试结果。本次 `.2` 构建的 Android 16 真机验证待完成。
- [APK、源码及校验清单](https://github.com/heyinkcode/LanduBrowser/releases/tag/v1.0.26-android.20261105.2) · [测试记录](TESTING.md)。

## Android v1.0.26-android.20261105.1（2026-11-05）

- 修复已捕获的 Adreno Vulkan 性能提示触发 Dawn 断言、导致 GPU 子进程退出的问题；保留 WebGPU 与 GPU 加速。
- 岚渡发行版本为 `1.0.26.20261105.1`，Android 版本码递增为 `807804805`。“关于岚渡浏览器”和 Android 安装信息可区分此次更新；真实 Chromium 内核仍为 `156.0.8078.48`。
- UA 自动推荐改为读取包内真实内核版本，与岚渡发行版本分开。
- 新增与桌面操作对应的“按系统生成 UA”“随机 UA”“跟随自动”和 Chrome 主版本输入，生成时同步 UA 与 UA-CH。
- 新环境预选独立随机档案，覆盖 9 种安卓型号及 Android 15/16。生成结果随环境保存，点击随机可更换型号，也可选择跟随本机。
- 编辑页展示上次启动的实际出口、语言、时区、坐标和检测时间，便于核对按出口 IP 的区域策略。
- 修复虚拟定位沿用手机传感器权限检查的问题。按出口 IP 和自定义坐标使用环境中的有效坐标，网站仍需定位授权。跟随设备模式沿用 Android 定位权限。
- 出口查询增加备用 HTTPS 服务。主服务限流、响应无效或请求失败时，沿用该环境的代理及认证重试一次；两者均失败时，依赖出口 IP 的策略会提示失败并停止启动。
- Redmi Note 12 Turbo / Android 15 完成保留数据更新、两轮各 8 组 WebGPU 渲染及像素检查，以及 7 个地址共 21 次页面导航。安装后的检查未发现新增崩溃日志。
- 本次 GPU 修复尚未覆盖 Android 16 与其他机型，不宣称所有“崩溃啦”均由同一个原因引起。

[GPU 修复和验证详情](ANDROID-GPU-STABILITY.md) · [安卓使用](ANDROID.md)
