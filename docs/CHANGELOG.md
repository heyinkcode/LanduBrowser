## 2026-11-05 · Android 1.0.26.20261105.1

- 精确过滤已确认的 Adreno `VKDBGUTILWARN003` 性能提示，修复其触发 Dawn 断言的问题，继续处理其他真实 Vulkan 校验错误。
- 新增独立的岚渡发行版本，版本码为 `807804805`，内核仍为 `156.0.8078.48`。Android 安装信息及“关于岚渡浏览器”可查看发行版本。
- UA 自动推荐使用真实内核版本，与应用发行版本解耦。
- 新增与桌面操作对应的“按系统生成 UA”“随机 UA”“跟随自动”和 Chrome 主版本输入，生成时同步 UA 与 UA-CH。
- 新环境预选独立随机档案，覆盖 9 种安卓型号及 Android 15/16。生成结果随环境保存，点击随机可更换型号，也可选择跟随本机。
- 编辑页展示上次启动的实际出口、语言、时区、坐标和检测时间，便于核对按出口 IP 的区域策略。
- Android 15 真机在手机定位权限关闭时，通过网站授权取得出口附近的虚拟位置，网站拒绝授权仍有效。
- 修复虚拟定位沿用手机传感器权限检查的问题。按出口 IP 和自定义坐标使用环境中的有效坐标，网站仍需定位授权。跟随设备模式沿用 Android 定位权限。
- 出口查询增加备用 HTTPS 服务。主服务限流、响应无效或请求失败时，沿用该环境的代理及认证重试一次，两者均失败时，依赖出口 IP 的策略会提示失败并停止启动。
- Android 15 指定真机完成覆盖更新与环境保留检查，GPU 修复测试及 21 次多网站导航通过。Android 16 尚未复测本次 GPU 修复。
- 下载 [APK、源码及校验清单](https://github.com/heyinkcode/LanduBrowser/releases/tag/v1.0.26-android.20261105.1) · [修复记录](ANDROID-GPU-STABILITY.md)。
