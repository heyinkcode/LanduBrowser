## 2026-11-06 · Android 15 RAF 大间隔排查

本轮使用 Redmi Note 12 Turbo / Android 15，安装包为 `1.0.26.20261105.2` / `807804806`。真机安装文件的 SHA-256 与该发布包一致。

检测页在启动时错开约 60ms 启动多组探针，多个任务会同时处于运行状态。RAF 探针在每次回调中读取 `performance.now()`，以短采样窗口的均值生成结果。源码来自本次下载的[检测页探针脚本](https://cdn.ping0.cc/js/envdetect/probes/index.js)及[检测调度脚本](https://cdn.ping0.cc/js/envdetect/main.js)。

### 同机、同环境对照

| 场景 | 实测 RAF 间隔 | 同步观察 |
| --- | --- | --- |
| 完整检测 | 403.85ms | 另一轮启动采样出现 66 个长任务，合计约 16.1 秒 |
| 页面空闲后的连续 120 个间隔 | 回调时间戳均值 16.78ms，performance.now 均值 16.78ms | 可见状态，无长任务 |
| 检测页同一个 RAF 探针单独运行三次 | 17.31、16.46、16.38ms | 完整检测保留的原结果仍为 403.85ms |
| RAF 探针与引擎探针并行 | 17.55ms | 引擎探针整体耗时约 6.45 秒 |
| RAF 探针与硬件探针并行 | 1421.20ms | 硬件组约 11.31 秒，出现约 9.48 秒的单次长任务 |

启动阶段同一组回调中，RAF 时间戳、performance.now 和 Date.now 的平均间隔分别约 418.72、418.51 和 418.50ms，三种时钟均记录了实际停顿。此前高读数与空闲采样的差异对应不同负载阶段。

### 硬件组耗时细分

一次临时 API 计时中，硬件组整体耗时约 12.47 秒。Canvas 上下文获取 11 次约 31.9ms，文本绘制 10 次约 4.7ms，Canvas 导出 5 次约 47.2ms，文字测量 1012 次约 559.9ms。CPU 采样热点还包括探针脚本的字符串解码函数和垃圾回收。临时计时包装已恢复，诊断标签页已关闭，原有标签页核验保留。

这组对照复现了硬件指纹探针占用主线程时 RAF 回调被延迟的触发路径。完整检测繁忙阶段仍可能记录大间隔。该结论覆盖本次 Android 15、当前环境及当前版本检测脚本的测量。

RAF 限帧器实际集成头文件与仓库文件的 SHA-256 一致，原有 52 组调度检查通过，覆盖设备帧率、设置上限、独立上下文、空闲恢复及时间回退。此次记录作为 `.2` 安装包的补充验证发布。

运行性能分析方法参考 [Chrome DevTools 官方文档](https://developer.chrome.com/docs/devtools/performance)。
