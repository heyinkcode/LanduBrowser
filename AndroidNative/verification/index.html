GPU 标识

核对主页面、iframe、Dedicated Worker 的标识、扩展权限和 GPUDevice.adapterInfo。API 缺失、超时或不一致不算通过。此项不验证像素噪声、图形能力画像或安装包来源。

浏览器身份与 Client Hints

覆盖页面、iframe、Dedicated Worker、Service Worker 及导航请求，核对低/高熵 Client Hints、实际请求头和固定内核版本。页面与导航必须发送匹配的请求头；worker 原生不发送整套 UA Client Hints 时会单独记录，已发送的值仍需一致。默认冻结的 Android 10 / K UA 按 Chromium 规则接受；自定义模式下型号留空会严格核对为空。

Do Not Track

核对页面与 iframe 的 navigator.doNotTrack，以及导航、页面、iframe、Dedicated Worker、Service Worker 发起的实际请求。先在环境中开启、重启检查，再关闭并重启复查。网站是否遵守 DNT 不在本检查范围内。

中文与厂商字体隔离

先关闭该环境的字体隔离，重启环境后检测并保存报告；再开启隔离、重启，载入同一设备的报告后对照。检查 CSS 布局、Canvas / OffscreenCanvas 和 local() 字体加载。设备原本没有对应字体时只记为“未观察到”，不会据此宣布隔离成功。

Canvas 环境指纹

先关闭该环境的固定噪声，重启并保存对照报告；再开启噪声、重启后载入报告检查。核对主页面、iframe、Dedicated Worker 和 Service Worker，直接解析 PNG 导出的像素，检查透明区域、重复读取、截取区域和写回稳定性。本轮使用 RGBA8 已知图案，HDR 与 WebGL 仍需另外验收。

WebGL 环境像素

使用环境中的“固定环境噪声”开关；先关闭并重启保存对照，再开启并重启后检查。核对 WebGL1/2、HTML/OffscreenCanvas、iframe 和 Dedicated Worker，以及偏移、行间距、PBO 复制、错误保留和直接解码 PNG。这里只验收已知 RGBA8 图案，不代表全部格式或 WebGPU 像素已经验收。报告仅保存在本机。
